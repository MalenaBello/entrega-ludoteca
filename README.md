# Comparación y Generación de Sitios Web con IA

Este repositorio contiene el código generado para la **Actividad de Teoría**, cuyo objetivo es contrastar y evaluar la generación de páginas web utilizando distintas herramientas de Inteligencia Artificial (por ejemplo, Claude y Microsoft Copilot).

---

## Estructura del repositorio

* `/copilot`: Código HTML, hoja de estilos `estilosIA.css` y carpeta `/imágenes` generados a partir de las interacciones con Microsoft Copilot.
* `/claude`: Código HTML, hoja de estilos `estilosIA.css` y recursos generados a partir de las interacciones con Claude.

---

## Restricciones y objetivos de la consigna

* **Lenguajes:** Estricto HTML5 y CSS sin interacción dinámica ni scripts de JavaScript.
* **Estilos:** Hojas de estilo externas denominadas `estilosIA.css`.
* **Recursos:** Almacenamiento local de recursos gráficos en la carpeta física `imágenes/`.
* **Evaluación:** Análisis manual de semántica, responsividad y accesibilidad, complementado con validadores W3C, WAVE y lectores de pantalla.
